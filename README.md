A tiny courier game in seven builds, and the film that compares build 1 with build 7. The seven builds were made back to back in one AI agent session for a [make.fun](https://make.fun) bounty.

Serve the folder over HTTP and open `index.html` to play. `node render.mjs <font.ttf> clip.mp4` and `node music.mjs music.wav` make the film's parts; ffmpeg adds make.fun's referral end card. `main.ts` hands in `VIDEO.json`.
